# WASP ASP Exercise — Unsolvability Classifier

Student exercise for the WASP Relational Learning course: learn an Answer Set
Programming classifier that distinguishes solvable from unsolvable planning
states. Open `wasp-unsolvability-classifier.ipynb` and work through Steps 0–6.

## Getting Started

1. Create and activate a Python virtual environment

```sh
uv venv --seed
source .venv/bin/activate
```

2. Install Jupyter Lab

```sh
uv pip install jupyterlab
```

3. Launch Jupyter Lab

```sh
jupyter lab
```
